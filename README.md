# proyecto-integrador-base-de-datos-1
#  Sistema de Gestión Deportivo - Club Deportivo 300%

##  Descripción del Proyecto
Este repositorio contiene el diseño, modelado y documentación del esquema relacional de base de datos para la gestión administrativa y operacional del **Club Deportivo 300%**. 

La institución está enfocada en la formación integral y el desarrollo competitivo de niños y jóvenes entre los **6 y 20 años**. Actualmente, administra una población activa de aproximadamente **300 deportistas** distribuidos en **8 categorías** (desde Sub-8 hasta Sub-20) a través de **4 disciplinas deportivas** (Fútbol, Básquetbol, Voleibol y Tenis). 

El sistema centraliza la información general del personal (estudiantes, entrenadores y acudientes), la programación en los **4 escenarios/canchas de entrenamiento**, el control de asistencias a cargo de los **8 entrenadores certificados**, y el seguimiento de pagos e inscripciones gestionados por el área administrativa.
